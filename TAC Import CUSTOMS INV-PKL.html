Save & Export

Save the combined shipment details in this browser, then export one worksheet named TAC INV + PL. The Commercial Invoice and Packing List print as two separate pages.

Export Excel downloads the Invoice + Packing List straight away, no need to save first. Save shipment stores the shipment and its Excel file in Saved Shipment History and adds it to the Updated Delivery to Production file (download it with the button under Export Excel).

Saved Shipment History

Every time you press Save shipment, the shipment and its Excel file (Commercial Invoice + Packing List) are stored here, in this browser only. Saving the same Declared Invoice Number + Country again adds a new row (it does not replace the old one), so you can track each version by Saved date / time. Use Download for the Excel file, Load to reopen the shipment in the dashboard, or Delete to remove it.
